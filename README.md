# Ironlady-task-2

🧠 Iron Lady – Internal Business Automation System
📌 Project Overview

This project is a Spring Boot + MySQL based internal business automation system designed for Iron Lady to manage learner/customer enquiries efficiently.
It replaces manual tracking (Excel, WhatsApp, emails) with a centralized CRUD-based web service.

The application supports Create, Read, Update, and Delete (CRUD) operations for managing program enquiries.

🎯 Business Problem

Iron Lady handles multiple learner enquiries across different programs.
Manually tracking:
-> Enquiry details
-> Program status
-> Follow-ups
is time-consuming and error-prone.

💡 Solution

A backend system that:
-> Stores enquiries in a MySQL database
-> Allows internal teams to manage learner status
-> Improves accuracy and efficiency
-> Reduces manual effort

🛠️ Tech Stack

-> Backend: Java, Spring Boot
-> Database: MySQL
-> ORM: Spring Data JPA (Hibernate)
-> API Testing: Postman
-> IDE: Eclipse
-> Build Tool: Maven
-> Server: Embedded Tomcat
